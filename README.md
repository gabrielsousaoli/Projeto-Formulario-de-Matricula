# 📝 Página de Formulários em HTML e CSS

> Página de formulários desenvolvida para praticar a criação e estilização de campos de formulário utilizando apenas HTML e CSS.

## 🧠 Sobre o projeto

Este projeto foi desenvolvido durante o curso Full-Stack da Rocketseat com o objetivo de praticar o uso da tag `<form>` no HTML, além da estilização de campos e botões com CSS.

Durante o desenvolvimento, foram utilizados diferentes tipos de inputs e controles de formulário, como **radio**, **checkbox** e **select**, focando em semântica, usabilidade e layout.

---

## 🛠️ Tecnologias utilizadas

- HTML5  
- CSS3  

---

## ✨ Funcionalidades

- [x] Campos de texto (input, textarea)  
- [x] Botões estilizados  
- [x] Seleção com radio buttons  
- [x] Seleção múltipla com checkbox  
- [x] Dropdown com select  
- [x] Layout organizado e estilizado  

---

## 🎯 Aprendizados

- Uso da tag `<form>`  
- Inputs de texto, email, senha, etc.  
- Estilização de inputs e botões com CSS  
- Radio buttons e checkboxes  
- Select e option  
- Organização visual de formulários
